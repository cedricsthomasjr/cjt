# cjst.dev

Personal site for CJ Thomas — AI/ML and data engineering.

```bash
npm install
npm run dev
```

## Design system

Two typefaces, two registers. **Helvetica Neue Bold** carries every claim, heading, and
figure. **Palatino Italic** carries every explanation. There is no third category, which
is what keeps it disciplined.

Both are licensed faces that ship with macOS and iOS, so most visitors get the genuine
articles from the system at zero cost. Everyone else falls through to **TeX Gyre Heros**
and **TeX Gyre Pagella** — freely licensed (GUST Font License) clones, subset and
self-hosted in `public/fonts` at ~46 KB total. The webfonts sit *ahead* of Helvetica and
Arial in the stack because Windows silently substitutes Arial for Helvetica; browsers
only download a webfont they actually use, so Mac visitors pay nothing for them.

Tokens live in `@theme` in `src/app/globals.css`. The accent is deliberately scarce —
under about 5% of pixels — because it reads cheap at any higher dose.

| Token | Value | Use |
| --- | --- | --- |
| `--color-ink` | `#08080A` | page |
| `--color-raised` | `#101014` | panels |
| `--color-rule` | `#1E1E24` | hairlines |
| `--color-gold` | `#C84036` | accent, figures |
| `--color-gold-lift` | `#E8908A` | hover |
| `--color-bone` | `#ECE9E2` | text |
| `--color-muted` | `#8A8781` | subtext |

## Conventions

- **Every page is a server component** except `ContactForm`, which needs state.
- **Motion is one orchestrated reveal** on the home hero (`.rise`), plus hover states.
  Nothing fades in on scroll. `prefers-reduced-motion` is honored globally.
- **Screenshots are desaturated in grids** (`.shot`) so unrelated app palettes read as
  one system, and shown in full colour on case-study pages.
- **No fake data encoding.** The hero readout has no magnitude bars because hours,
  dollars, and row counts share no scale.
- Projects without a screenshot get a typographic plate rather than a generated
  placeholder.

## Content

- `src/data/projects.json` — projects; drives `/projects`, the slug pages, and the
  resume's project list. `image: null` triggers the typographic plate.
- `src/data/resume.js` — contact links, the hero `record` figures, and resume sections.

Every figure in `record` is verifiable from the resume. Keep it that way.

## Assets

`public/og.png` is generated by a script kept out of the repo; regenerate it if the
hero figures change. Screenshots in `public/projects` are cropped to page content —
no browser chrome, no bookmarks bar.
